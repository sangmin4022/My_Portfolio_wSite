# My Portfolio

This is a developer portfolio website showcasing various projects. The portfolio is designed to be clean, sophisticated, and user-friendly.

## Project Structure

```
my-portfolio
├── index.html          # Main HTML document for the portfolio
├── styles              # Directory for CSS styles
│   └── main.css        # Styles for the portfolio website
├── scripts             # Directory for JavaScript files
│   └── main.js         # JavaScript for dynamic content loading
├── data                # Directory for data files
│   └── projects.json   # JSON file containing project data
├── assets              # Directory for assets
│   └── icons           # Icons used in the portfolio
└── README.md           # Documentation for the project
```

## Setup Instructions

1. Clone the repository or download the project files.
2. Open `index.html` in a web browser to view the portfolio.
3. Customize the `projects.json` file to add your own projects.

## Features

- Dynamic loading of project data from a JSON file.
- Clean and sophisticated design with responsive layout.
- Interactive elements powered by JavaScript.

## Customization

- Modify the `projects.json` file to update project details.
- Change styles in `styles/main.css` to match your personal branding.
- Add or replace icons in the `assets/icons` directory as needed.
